# VitaTrack
VitaTrack 2.0 é um site web para acompanhar hábitos e bem-estar de forma simples, moderna, organizada e útil. Permite registrar hidratação, sono, atividades físicas, humor e hábitos, definir metas, acompanhar estatísticas, visualizar o histórico e conquistar objetivos. Possui tema claro e escuro, interface responsiva e armazenamento local e privado
